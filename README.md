# Analyzing-Global-Music-Trends
This repository contains a `.ipynb` file with our team’s exploration of global music trends using Discogs data. We used PySpark, machine learning, and data visualization to examine how music genres, artists, and formats have evolved over the decades.

## Features and Findings
We analyzed four datasets (masters, artists, labels, and releases) to:
- Track genre and artist production trends over time.
- Compare growth/decline periods across genres and formats.
- Apply ML models (logistic regression, SVM, random forest) for classification and clustering.
- Reveal patterns like the dominance of solo artists and the rise of multi-genre releases.

Our analysis shows how music trends reflect larger cultural and technological shifts. The work also demonstrates how machine learning can support genre tagging and recommendation engines for streaming platforms.
